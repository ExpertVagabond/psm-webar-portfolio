# PSM WebAR Portfolio

3D portfolio showcase with face-tracking effects and interactive AR project displays.

## Stack
- Vite
- JavaScript
- Three.js
- MediaPipe Face Mesh

## Deploy
- URL: https://psm-webar-portfolio.pages.dev
- Build: `npm run build`
- Deploy: `wrangler pages deploy dist`

## Dev
- `npm run dev` -- local server
- `npm run build` -- production build
